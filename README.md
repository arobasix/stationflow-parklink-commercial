# StationFlow — concept ParkLink

Site commercial indépendant pour présenter l’offre de cadrage et de pilote de stationnement intelligent.

## Pages

- `index.html` — présentation commerciale
- `investissement.html` — plan d’investissement détaillé
- `amortissement.html` — plan d’amortissement détaillé

Les hypothèses financières sont indicatives et doivent être confirmées par devis, contrat, fournisseurs et conseils du client.

## Publication

Le workflow GitHub Pages publie le contenu statique de la branche principale. Le dépôt prévu est indépendant des dépôts existants `arobasix/arobasix` et `arobasix/arobasix-bis`.
